Timeline — Elapsed Delta

The elapsed delta timeline plots the timing difference for each event between the before and after traces. Each vertical bar represents one matched event — bars above the center line indicate the after trace was slower; bars below indicate it was faster.

markers indicate the after trace took longer (regression); markers indicate improvement.

Vertical tick lines mark time intervals on the shared scale. Use the zoom controls to magnify the timeline and reveal finer detail.

Use the view mode dropdown to filter which events are displayed — for example, show only diff events, state events, or a specific category.
