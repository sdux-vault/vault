Compare Traces

Compare Traces shows a side-by-side diff of two trace executions through the same pipeline. Use it to verify that a code change produced the expected result or to pinpoint where behavior diverged.

Summary bar

  • X of Y events differ — how many events changed between the before and after traces out of the total.
  • Before / After duration — total pipeline execution time for each trace in milliseconds.
  • Duration delta — the speed difference (e.g. "−300ms faster" or "+50ms slower"), highlighted green for faster and red for slower.

Filters

  • Diffs Only — hide matching events and show only the ones that changed between traces.
  • Category buttons (lifecycle, controller, etc.) — show only events belonging to that category.
  • state — show only events that carry a state snapshot, useful for isolating state transitions.
