How to install the license
  • Copy the entire license object exactly as provided.
  • Add the license to your Vault configuration inside the licenses array during initialization.
  • Paste the license object directly into your configuration or store it in a dedicated file and import it into the licenses array.
  • Restart your application after adding the license to ensure Vault initialization and validation completes successfully.
