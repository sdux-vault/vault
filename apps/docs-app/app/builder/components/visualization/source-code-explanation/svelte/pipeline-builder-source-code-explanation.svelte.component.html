Generated Example Files

This page contains the full, generated source output for the pipeline configuration you selected in the Builder. These files are designed to be copy/paste ready and follow best practices: the module-scope owns the Vault, components consume the reactive state snapshot, and all updates flow through exported cell functions so the pipeline remains deterministic and consistent.

What You're Looking At

  • installation — The minimal install command for the packages required by your selection.
  • example.cell.ts — The module-scope that initializes the Vault, registers the cell, and configures the runtime pipeline via the fluent API. Exported functions provide the public API for state updates.
  • ExampleView.svelte — A Svelte component that bridges the Vault's reactive state stream into Svelte reactivity via the $state rune and onDestroy lifecycle hook, and delegates state updates to the cell module's exported functions.
  • main.ts — The application entry point that mounts the root component.

How to Use These Files

  • Start with installation and install the listed packages in your project.
  • Copy the files into your app (or use them as reference templates).
  • Rename placeholders (cell name, state type, and key) to match your domain.
  • Keep Vault access inside the cell module — components should only read the exported state and call exported functions to update state.

Important

  • The generated pipeline configuration is deterministic: it is defined at module scope and activated only when initialize() is called.
  • If you add or remove behaviors in the Builder, this output will change to match your new pipeline configuration.
  • Use the Copy button on each file to copy the source directly.
