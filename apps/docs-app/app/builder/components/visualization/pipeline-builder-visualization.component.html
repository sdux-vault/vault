AI Assist – Guided Code Generation

This file contains structured, production-grade prompts designed to help you generate deterministic, pipeline-safe TypeScript functions using any modern AI model (ChatGPT, Claude, Copilot, etc.). Each snippet is tailored to the specific pipeline behaviors you selected in the Builder, so you can quickly produce correct, pure, and structurally safe implementations that conform to the pipeline contract.

How to Use This File

  • Copy one snippet at a time into your preferred AI model.
  • Replace the “Engineer Action” sections with your real state shape and logic.
  • Delete unused implementation patterns before submitting.
  • Submit the refined prompt to the AI and paste the generated TypeScript into your project.
  • Verify correctness against your domain rules and add/adjust tests as needed.

Important

  • These prompts are intentionally strict to enforce determinism, immutability, and structural integrity.
  • The AI is instructed to return only valid TypeScript code (no explanations).
  • The Pipeline Builder generates the architecture; AI Assist helps generate the implementation.
