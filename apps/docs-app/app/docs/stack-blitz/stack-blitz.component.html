StackBlitz Examples

StackBlitz Examples are live, runnable projects that demonstrate how manages state across multiple frameworks. Each example launches directly in StackBlitz with all dependencies pre-configured—no local setup required.

Every example implements the same pipeline logic regardless of framework. Filters, reducers, lifecycle signals, and immutable state snapshots behave identically whether you choose Angular, React, Vue, or Svelte. The only differences are the thin framework adapters that bind pipeline output to the UI.

Select a framework from any example below to open it in StackBlitz. Modify the pipeline, add behaviors, or extend the state shape—all changes run immediately in the browser.
