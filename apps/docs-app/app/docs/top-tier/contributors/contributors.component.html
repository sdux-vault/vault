Community & Contributor Call

is a TypeScript-first, framework-agnostic state system. It is not owned by a single framework, or ecosystem. Its long-term success depends on a shared, cross-framework community.

This page is a direct call for contributors, maintainers, reviewers, and ecosystem representatives. If you care about predictable state management, deterministic execution, and clean architectural boundaries, this is an opportunity to help shape a shared foundation across Angular, React, Vue, and beyond.

Why This Project Matters

The JavaScript ecosystem has repeatedly fragmented state management solutions by framework. takes a different approach:

  • A single deterministic core runtime
  • Framework adapters layered on top
  • Composable behaviors instead of monolithic state engines
  • Formal execution guarantees and test stabilization boundaries

This architecture only works if engineers from multiple ecosystems help steward it. A framework-agnostic core must not drift toward a single framework’s assumptions.

How to Contribute (GitHub Workflow)

All collaboration occurs openly through GitHub.

1. Start with Issues

  • Review open issues labeled good first issue
  • Comment before starting significant work
  • Propose RFC-style issues for architectural changes

2. Fork and Branch

  • Create a feature branch from main
  • Use clear branch naming (feature/, fix/, docs/)
  • Keep pull requests focused and atomic

3. Pull Requests

  • Reference related issue numbers
  • Include tests for behavior changes
  • Update documentation when API surfaces change
  • Pass all CI checks before review

4. Reviews

Reviews focus on:

  • Deterministic execution preservation
  • Immutability discipline
  • Framework neutrality
  • Type safety and inference integrity
Maintainers & Repository Stewards

We are seeking long-term maintainers for:

  • /core – Runtime, pipeline engine, behavior contracts
  • /angular – Angular adapter and signals integration
  • /devtools – Observability and debugging tooling
  • Future React and Vue adapter packages

Maintainers are responsible for:

  • Reviewing pull requests
  • Enforcing architectural boundaries
  • Managing issue triage
  • Coordinating minor and major releases
  • Preventing framework bias in core decisions

If you are interested in repository stewardship, please open a discussion issue outlining your experience, ecosystem involvement, and intended scope of contribution.

Contribution Principles
  • Determinism over convenience
  • Explicit boundaries over implicit magic
  • Framework neutrality over ecosystem favoritism
  • Tests are non-negotiable
  • Documentation must evolve alongside code

Architectural consistency is more important than rapid feature growth. Stability and clarity are foundational values.
