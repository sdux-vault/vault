Step 17: Complete Delete Tutorial
↑ top

The delete tutorial is complete once the page can stage a pending delete, cancel that destructive action, confirm removal of the selected record, and react cleanly when the collection becomes smaller or empty. The boundary still has not moved: the service owns the , and the component owns only local selection, editor, confirmation, and feedback state.

This chapter keeps the implementation disciplined even while it adds a destructive action. The component presents a confirmation panel, clears local selection after a confirmed removal, and returns the editor to a safe create-ready state. The architectural rule stays fixed: the component does not call APIs directly, and it does not own committed Feature State. Delete is routed through the same service-owned boundary as every other mutation.
