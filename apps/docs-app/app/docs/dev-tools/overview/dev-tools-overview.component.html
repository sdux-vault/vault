DevTools Overview

includes a small set of development tools designed to help engineers inspect, understand, and debug Vault pipeline execution.

These tools expose runtime telemetry generated by the Vault execution engine, allowing developers to observe pipeline behavior, record execution traces, and build custom debugging or analytics utilities during development.

The DevTools ecosystem is composed of four core components: the built-in debugger, the Chrome Extension, the Vault Monitor telemetry system, and the Event Bus used to deliver runtime events to development tooling.

Built-in Debugger

The built-in debugger provides a lightweight runtime panel that records pipeline execution activity for instances.

During a recording session the debugger captures lifecycle transitions, controller activity, stage execution, and error signals emitted by the Vault pipeline. These events can be exported as diagnostic logs or analyzed using the AI Assist feature.

The debugger operates as a passive observer and does not alter pipeline behavior. It simply records the telemetry produced by the Vault Monitor during development.

Chrome Extension

The Chrome Extension provides a dedicated DevTools panel for inspecting Pipeline execution directly within Chrome Developer Tools. The extension consumes the same telemetry produced by the Vault Monitor and presents it through interactive report views.

Reports include trace timelines, State diff comparison, hot stage ranking, Pipeline replay, extension inspection, and AI-assisted diagnostics. Each report view includes inline help that describes its purpose and usage.

Read the Chrome Devtools Extension documentation →

Vault Monitor

The Vault Monitor is the internal telemetry system responsible for observing pipeline execution and producing structured runtime events.

As the Vault pipeline runs, the monitor records lifecycle transitions, pipeline stage activity, controller decisions, and runtime errors. These signals are normalized into a consistent event format used by development tools.

The monitor operates passively and does not influence pipeline execution. Its sole responsibility is to produce structured telemetry that development tools can inspect.

Read the Vault Monitor documentation →

Event Bus

The Event Bus provides the runtime event stream used by DevTools and custom diagnostics systems.

Events emitted by the Vault Monitor are forwarded to the Event Bus, where they become available as an observable stream. Development tools subscribe to this stream to record, inspect, or analyze pipeline behavior.

Because the Event Bus exposes raw pipeline telemetry, developers can also use it to build custom DevTools, analytics dashboards, or debugging utilities.
