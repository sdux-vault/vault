Pipeline

Seven stages. One direction. Zero ambiguity.

Ordered. Predictable. Traceable.

1

Controllers

Policy-driven governance. Control when, how, and whether execution proceeds.

2

Interceptors

Guard and transform incoming actions before they reach the pipeline. Validate, enrich, or reject at the gate.

3

Resolve

Async data resolution. Fetch what you need before state commits.

4

Filters

Conditional execution gates. Skip or allow pipeline continuation based on current state or action shape.

5

Reducers

Pure state transformations. Deterministic computation with zero side effects.

6

Taps

Observe committed state without modifying it. Logging, analytics, sync triggers.

7

Extensions

Post-commit behaviors like persistence and encryption. State remains pure; extensions act on committed output.

Ownership

One feature. One cell. One truth.

FeatureCells encapsulate state, pipeline, and lifecycle into a single boundary that a team can own entirely.

Isolated typed state — each domain feature gets its own cell with typed state and scoped pipeline.

Scoped pipeline — dedicated stages per feature with no cross-feature state leaks.

Lifecycle-aware — cells mount and unmount with their feature, releasing memory and subscriptions automatically.

Team-scale boundaries — one team owns one cell. No cross-feature state leaks. 

const cartCell =
  new FeatureCell<CartState>({
  name: 'cart',
  initialState: {
    items: [],
    total: 0,
    status: 'idle'
  }
});

cartCell.replaceState({
  value: {
    items: updatedItems,
    total: computeTotal(items),
    status: 'ready'
  }
});
